CPP Modules 00 to 04 of 42 Curriculum. We learn the basics of object-oriented programming on C++.

Rules:

We use the C++98 standard.
No norminette.
Forbidden functions: *printf(), *alloc() and free().
Allowed to use the STL only in Modules 08 and 09.
From Module 02 to Module 09, classes must be designed in the "Orthodox Canonical Form".
Must use include guards to avoid double inclusion.
using namespace <ns_name> and friend keywords are forbidden.
